# Third-Party Notices and Conceptual Prior Art

DragonFruitMe v0.1.0 is independently implemented. It does not vendor source code from the projects below.

- Crawlee for Python — https://github.com/apify/crawlee-python — Apache-2.0 — adaptive HTTP/browser crawling, rendering-type prediction.
- Scrapling — https://github.com/D4Vinci/Scrapling — BSD-3-Clause — layered fetchers, adaptive selectors, MCP mode.
- Agent Reach — https://github.com/Panniantong/Agent-Reach — MIT — ordered per-platform fallback channels with health checks.
- ScrapeGraphAI — https://github.com/ScrapeGraphAI/Scrapegraph-ai — MIT — graph-based scraping pipelines with LLM nodes.
- AutoScraper — https://github.com/alirezamika/autoscraper — MIT — learning extraction rules from example values.
- Obscura — https://github.com/h4ckf0r0day/obscura — Rust headless browser for agents (candidate render engine; not used in v0.1.0).
- Playwright for Python — https://github.com/microsoft/playwright-python — Apache-2.0 — optional render stage (`browser` extra).
- Model Context Protocol Python SDK — https://github.com/modelcontextprotocol/python-sdk — MIT — optional MCP server (`mcp` extra).
